# Asset Guide

## Supplied source

- `assets/logo_pap.png` — canonical symbol, 3375 × 3375 RGBA PNG. Preserve this file unchanged; keep it as the source of all approved derivatives.

## Target folders

```text
public/assets/brand/          approved logo derivatives and favicon
public/assets/social/         OpenGraph and social previews
public/assets/icons/          Apple/PWA icons
public/assets/illustrations/  lightweight diagrams and approved visuals
```

## Generation and review

Run `npm run assets:generate` to copy the source unchanged into `public/assets/brand/` and generate proportional favicon, Apple touch, PWA/maskable, OG, and social-preview assets. Do not invent a wordmark or recolor artwork. For icons, center the mark on a contrast-safe background and review at native sizes. OG artwork uses approved brand colors and the supplied company name only; no unverified tagline, portrait, client logo or data visualization.

## Photography and media library

Use authentic, properly licensed corporate/operational photography after PAP approves the style and usage. Avoid generic handshakes, staged foreign call-center imagery, aggressive collection depictions, and fake crisis imagery. Store original, optimized derivatives, alt text, caption, credit, dimensions, MIME and license/source. Private CVs/documents must not be stored under public assets.
