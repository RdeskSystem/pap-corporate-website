# Roadmap

## Phase 1 — Discovery and architecture

- Inspect greenfield workspace and supplied brief/logo.
- Document requirements, routes, data model, security, design, SEO, accessibility, deployment and test strategy.
- Review architectural decisions and maintain a clear list of missing verified company inputs.

## Phase 2 — Foundation

- Bootstrap Next.js/TypeScript, shared layout, brand tokens and bilingual route handling.
- Build responsive public page templates with verified project inputs and honest empty states.
- Add metadata/robots/sitemap foundations and approved logo derivatives.

## Phase 3 — CMS and data

- Implement PostgreSQL/Prisma schema and migrations.
- Implement authentication, server-side RBAC, audit logging and structured bilingual editorial workflow.
- Build CMS dashboard, content modules, previews, media library and settings.

## Phase 4 — Public content and conversion

- Populate approved company profile, service/industry/process/compliance content, careers, news and legal pages.
- Build secure contact/application APIs, private CV storage, notifications and admin workflows.
- Add redirects, complete SEO/structured data and analytics configuration.

## Phase 5 — QA and release

- Unit/API/auth/RBAC/CMS/E2E testing; accessibility and responsive review; security and performance review.
- Configure staging/production, backup/restore, monitoring and rollback.
- Complete content verification and design review before declaring release-ready.

## Dependencies

The first missing external input is the company document expected tomorrow, especially official contact channels and approved company facts. Hosting/domain, PostgreSQL, storage, email, privacy/legal approval, and admin ownership are also required before production CMS/forms/deployment.
